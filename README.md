# Module 4 – Python Data & APIs: Sales Data Analysis

## Project Overview
A beginner-friendly Python data analysis application built with Pandas, NumPy and Matplotlib. It supports dataset loading, cleaning, analysis, visualization, REST API/JSON processing and report generation.

## Files
- `sales_data.csv` – sample dataset
- `Module4_Sales_Analysis.ipynb` – Google Colab/Jupyter notebook
- `app.py` – Streamlit data analysis application
- `requirements.txt` – required Python packages

## Run the application
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Technologies
Python, NumPy, Pandas, Matplotlib, Seaborn, Requests, Streamlit, REST API, JSON, Google Colab, GitHub.
